## 无哈希约定

按用户要求，本项目不计算、不比较、不检测任何哈希或校验和。所有验收使用路径、文件大小、修改时间、命令退出码、数值核对、PDF 对象检查和渲染视觉检查，这类检查不等价于密码学完整性证明。提交检查清单中与哈希相关的栏目保持未执行状态。
