# 审查与验收材料（reviews/）

本目录只保留这一份 README 在根层，其余材料统一归档在 `过程归档/` 中。归档材料不属于建模产物，也不参与程序运行；它们的作用是让论文参考稿的每个结论、口径和版式都可追溯。

## 还有用吗

有用，但只在追溯和复核时才会打开，日常建模、改代码和出图都不需要碰它们。

- 提交阶段若被质疑数值来源、统计口径或格式合规，可以据此回溯到具体命令和证据。
- 独立复现目录保留了在隔离环境重跑一遍的完整输入与日志，是结果可信度的主要凭据。
- 验收回执记录了 M1/P1/P2/W1/W2 五个门禁的状态，其中 W2 已给出 PASS。
- 归档内容可以整体打包保留，也可以按下面的“可清理项”自行精简；本次整理没有删除任何文件。

## 无哈希约定

按用户要求，本项目不计算、不比较、不检测任何哈希或校验和。所有验收使用路径、文件大小、修改时间、命令退出码、数值核对、PDF 对象检查和渲染视觉检查，这类检查不等价于密码学完整性证明。提交检查清单中与哈希相关的栏目保持未执行状态。
