# 术语与符号表

> 单位合同：原始负荷、光伏和充放电功率为 kW；进入优化前统一乘 \(\Delta t=1/6\) h 转为每时段 kWh；储能状态为 kWh；电价为元/kWh；费用为元。

## 一、核心术语

| 中文术语 | 英文/缩写 | 本项目定义 |
|---|---|---|
| 微网 | Microgrid, MG | 含小区负荷、光伏、储能和外部电网接口的局部电力系统 |
| 日前计划购电量 | Day-ahead purchase | 每日 0:00 基于当时信息确定的 144 点购电合同量 |
| 有效合同购电量 | Effective contracted purchase | 经 6/12/18 时调整后、实际进入物理平衡的购电量 |
| 调整购电量 | Adjusted purchase | 模板中记录的执行前最终有效合同量；费用只记录它相对 0:00 原计划的增减量，每时段结算一次 |
| 向上调整 | Upward adjustment | 执行前最终合同量高于 0:00 原计划的正差，按同期电价 1.5 倍计相关费用 |
| 向下调整 | Downward adjustment | 0:00 原计划高于执行前最终合同量的正差，按同期电价 0.5 倍计违约费用 |
| 应急购电 | Emergency purchase | 有效合同、光伏和储能放电仍不足时的补救购电，按同期电价 5 倍计费 |
| 弃光 | PV curtailment | 可用光伏中因负荷和储能限制而未被利用的部分 |
| 弃购 | Paid but unused purchase | 已按计划付费但未被负荷或储能消纳的计划电量，无退款、无售电收入 |
| 荷电状态 | State of charge, SOC | 储能当前电量；报告时可用 kWh 或占额定容量比例表示 |
| 日循环约束 | Daily cyclic constraint | 仅问题一要求同一典型日 0:00 与 24:00 的储能电量相同 |
| 分位数安全计划 | Quantile-calibrated schedule | 用历史联合误差情景校准保守负荷/光伏分位数，再以单阶段 LP 制定不可预见未来的计划 |
| 情景 | Scenario | 一条完整的负荷—光伏联合日轨迹及其概率 |
| 模型预测控制 | Model predictive control, MPC | 每次获得新预测后重算有限时域计划，仅执行到下一次更新 |
| 严格因果回测 | Causal rolling-origin backtest | 每个决策时刻只使用此前已发生或已发布的数据进行训练和决策 |
| 相似日 | Analog day | 由时间距离和星期类型加权、用于预测当前日曲线的历史日期 |
| 冷启动退化情景 | Cold-start degenerate scenario | 无历史残差时使用一条全零联合残差、概率 1；只确定启动策略，不表示首日真实误差为零 |
| 加权经验分位数 | Weighted empirical quantile | 对情景值排序，取累计归一权重首次达到目标分位的值，不在线性区间内插值 |
| 平局项 | Tie-breaker | 主经济目标最优后用于最小化储能吞吐、排除退化解的次级目标 |
| 信息泄漏 | Look-ahead leakage | 在某次预测或优化中使用该时刻尚不可获得的实际值或未来误差 |

## 二、集合与索引

| 符号 | 含义 | 取值 |
|---|---|---|
| \(d\) | 日期索引 | 2025-01-01 至 2025-12-31 |
| \(t\) | 10 min 时段索引 | \(1,\ldots,144\) |
| \(r\) | 日内预测/报价发布时刻 | 0、6、12、18 h |
| \(h\) | 小时预测提前期 | 1–24 h |
| \(\omega\) | 联合不确定性情景 | \(\omega\in\Omega\) |
| \(H\) | 候选日内更新时刻集合 | 基准为 \(\{0,6,12,18\}\) |

## 三、参数

| 符号 | 含义 | 单位/主值 |
|---|---|---|
| \(\Delta t\) | 单时段长度 | \(1/6\) h |
| \(T\) | 每日时段数 | 144 |
| \(L_{d,t}\) | 实际或预测负荷电量 | kWh/时段 |
| \(V_{d,t}\) | 实际或预测可用光伏电量 | kWh/时段 |
| \(c_{d,t}\) | 外部电网同期实际结算电价 | 元/kWh |
| \(\hat c_{d,t}^{(r)}\) | 第 r 次决策时可得的电价预测，仅用于问题四优化 | 元/kWh；历史 30 d 中位数加已观测短期误差修正 |
| \(E_{\max}\) | 储能额定容量 | 12000 kWh |
| \(S_{\min},S_{\max}\) | 允许储能电量边界 | 1200、10800 kWh |
| \(P_{\max}\) | 最大充/放电功率 | 5000 kW |
| \(B_{\max}\) | 单时段最大充/放电量 | 833.3333 kWh |
| \(\eta_c,\eta_d\) | 充电、放电效率 | 0.9、0.9 |
| \(S_0\) | 2025-01-01 0:00 初始电量 | 6000 kWh |
| \(\pi_\omega\) | 情景概率 | 非负且和为 1 |
| \(n_d,\rho_d\) | 前 90 d 内可用历史日数及先验收缩权重 | \(\rho_d=\min(1,n_d/21)\)；空历史直接用附件 1 |
| \(z_t^0\) | 题设典型日点预测先验 | kW；负荷、光伏分别取附件 1 |
| \(Q_\alpha\) | 情景加权经验逆分布分位数 | 与被统计变量同单位；单情景时等于该值 |
| \(\alpha_E\) | 应急购电倍率 | 5 |
| \(\alpha_+\) | 向上调整倍率 | 1.5 |
| \(\alpha_-\) | 向下调整违约倍率 | 0.5 |
| \(\kappa\) | 单次新增预测/报价管理成本 | 元/次；主分析为 0 并报告盈亏平衡值 |

| 符号 | 含义 | 单位/约束 |

| \(\delta^+_{d,t}\) | 最终合同相对 0:00 原计划的向上调整量 | kWh，\(\ge0\)；每时段只结算一次 |
| \(\delta^-_{d,t}\) | 0:00 原计划相对最终合同的向下调整量 | kWh，\(\ge0\)；每时段只结算一次 |

## 五、评价指标

| 指标 | 定义/用途 |
|---|---|
| MAE | 预测绝对误差均值，单位与原变量一致 |
| RMSE | 对较大误差更敏感的均方根误差 |
| MAPE | 仅对真值超过阈值的时段计算，避免光伏夜间除零 |
| 区间覆盖率 | 实际值落在预测加历史原始残差的 90% 经验区间内的比例；不等同于簇中心区间，也无有限样本覆盖保证 |
| 总购电费用 | 计划费 + 调整相关费 + 应急费 |
| 应急电量/次数 | 反映供电风险与预测不足 |
| 弃光率 | 弃光电量 / 可用光伏电量 |
| 弃购率 | 未消纳已付计划电量 / 计划购电量 |
| 储能吞吐量 | \(\sum_t(x_t+y_t)\)，反映调度强度 |
| 等效循环次数 | 储能吞吐量 / \((2E_{\max})\) |
| SOC 约束活跃率 | SOC 位于上下边界数值容差内的时段比例 |
| 更新净收益 | 基准费用减候选方案费用及管理成本 |

## 六、首次出现与禁止混用

物理变量与单位首次见分析报告第 4 节；日前预测、情景与安全分位数首次见第 6 节；发布时刻、调整与结算见第 7 节；预测电价见第 8 节。功率（kW）不可与时段电量（kWh）混用，SOC 电量不可与百分比混用；0.5 分位数不是未经修正的点预测，整点功率不是小时平均功率；已付费合同量不是实际消纳量，现金费用不是含储能残值的优化目标，合成临近预测不是附件真实发布的新预报。
