# 支撑材料文件列表

本清单对应项目目录中的 `支撑材料/` 文件夹，文件路径均以该文件夹为根目录。

## 01_程序代码/py/

| 文件 | 用途 |
|---|---|
| `run_lite.py` | 全流程运行入口 |
| `microgrid_core.py` | 公共参数、数据读取、预测与线性规划底层函数 |
| `solution_lib.py` | 年度仿真、滚动调度、结算与校验 |
| `问题1_求解.py` | 问题一典型日确定性优化 |
| `问题2_求解.py` | 问题二年度日前购电优化 |
| `问题3_求解.py` | 问题三日内合同调整优化 |
| `问题4_求解.py` | 问题四固定合同与可调合同方案 |
| `问题3_其他时刻增量.py` | 其他预报时点的增量收益计算 |
| `补充敏感性计算.py` | 初始储能、容量和功率等敏感性分析 |
| `终端价值敏感性.py` | 终端价值系数敏感性分析 |
| `收口计算.py` | 各问题关键数值复核 |
| `汇总结果.py` | 汇总各问题结果并生成论文表格数据 |

## 复现说明

程序依赖 Python 3.10 及以上版本，以及 `numpy`、`pandas` 和 `scipy`。进入 `01_程序代码/py/` 后运行：

```bash
python run_lite.py
```

使用 `python run_lite.py --list` 可仅查看复现步骤而不执行计算。
