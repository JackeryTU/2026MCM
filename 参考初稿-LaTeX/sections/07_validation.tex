\section{模型检验、敏感性与稳健性分析}

\subsection{物理可行性与因果性检验}

对问题一及四个年度主策略逐槽检查规划层式\eqref{eq:plan-balance}、式\eqref{eq:plan-soc}与执行层式\eqref{eq:exec-balance}、式\eqref{eq:exec-soc}，并核对SOC边界、充放电功率、非负性、同时充放和跨日连续性。正式主策略的最大真实母线平衡残差为 $4.55\times10^{-13}\,\mathrm{kWh}$；5010个规划LP全部返回\texttt{optimal}，最大LP等式残差为 $2.57\times10^{-11}\,\mathrm{kWh}$。规划层与执行层的最大同时充放量均为0。这些量接近浮点运算精度，说明输出满足本文两层物理方程。

因果性检验在第0、1和364日的0、2、\ldots、22时，对未来负荷、光伏、价格和未发布预报分别作36组扰动。当前预测、价格估计和当前LP计划的最大差均为0；已执行前缀和SOC边界也不受未来扰动影响。这验证了实现遵守信息集 $\mathcal F_{d,h}$。该检验说明“没有使用被扰动的未来数据”，但不是对所有可能代码路径的形式化证明。

\subsection{54组实验设计}

实验共54组，其中16组为固定价或变价条件下的安全轨迹、点预测、典型日、无储能，以及0/12/6/2小时更新基线；另有38组单因素实验。单因素范围包括：
\begin{itemize}
  \item 保守分位参数 $\alpha=0.70,0.75,0.80,0.85,0.90,0.95$；
  \item 聚类压缩消融的簇数上限5、9、12、16，以及残差历史30、60、90日；
  \item 储能容量和功率分别为主值的0.8、1.0、1.2倍；
  \item 往返效率从0.81提高到0.90，即单向效率改为 $\sqrt{0.9}$；
  \item 应急电价倍率3、4、5、6、8。
\end{itemize}
正式主模型始终采用未聚类原始残差；簇数扫描只评价压缩对照，不能解释为主模型调参。容量改变时，SOC下限、上限和初态仍分别为容量的10\%、90\%和50\%，而功率与效率保持不变；功率实验则不改变容量。应急倍率实验固定物理策略和 $\alpha=0.8$，只重新计算费用暴露，因此不能称为各倍率下重新寻优的最优策略。

\subsection{规划--执行一致性诊断}

LP中的连续变量仅包括合同、规划光伏利用、规划充放电、目标SOC；允许调账时再加入合同调整差分。应急购电 $u_t$ 和闲置合同 $w_t$ 只在真实量到达后由因果贪心反馈确定，是执行与结算记账量，不是LP决策变量。由此，计划目标SOC与真实执行SOC出现偏差是预测误差经反馈层吸收的结果，并不表示违反状态方程。

四个正式主分支的目标SOC日均绝对偏差分别为：问题二 $1272.24\,\mathrm{kWh}$、问题三 $801.76\,\mathrm{kWh}$、问题四无调账 $1320.57\,\mathrm{kWh}$、问题四有调账 $840.82\,\mathrm{kWh}$。有调账分支偏差较小，说明日内新信息使后续计划更贴近真实执行；但偏差不为0也表明滚动合同层不能替代执行反馈层。本文据此把整体框架固定称为“合同层滚动线性规划 + 因果贪心反馈”。

\subsection{结算与时间口径敏感性}

同一策略在主结算和替代结算下费用差异明显。问题三主策略由1622.24万元增至1702.57万元，问题四有调账策略由1667.05万元增至1743.15万元。更重要的是，固定价下2小时相对6小时的节省从62.84万元缩小为0.91万元，变价下从62.60万元缩小为2.55万元。因此，更新频率结论必须与式\eqref{eq:settlement-primary}绑定，不能只给一个脱离合同条款的百分比。

时间口径实验把典型日全部槽循环平移10分钟。购电总量仅有约 $2.38\times10^{-9}\,\mathrm{kWh}$ 的浮点差，而费用下降约0.10元。结果表明年度策略量级不依赖这一微小映射，但题目指定时段数值和逐槽费用仍需要统一定义，本文采用区间终点解释。

\subsection{计算规模与结果可追溯性}

每天的规划域最多为144槽，随日内时间推进逐步缩短。每槽LP包含合同、规划光伏利用、规划充放电与目标SOC；调账分支再包含相对0时合同的调整差分。约束数量随剩余槽数线性增长，所有目标和约束均为线性形式。未聚类正式模式直接从最近60个已完成日期提取边际经验分位数，不含随机步骤；聚类只作为288维联合残差的压缩消融，固定种子2026和10次初始化。

为了使结果可追溯，每个策略同时保留三层输出：第一层是逐槽规划合同、目标SOC与真实能量流，用于分别检查式\eqref{eq:plan-balance}、式\eqref{eq:plan-soc}和式\eqref{eq:exec-balance}、式\eqref{eq:exec-soc}；第二层是每日合同量、现金费用、应急量、闲置合同和弃光；第三层是334日总量及实验参数。论文汇总与五份题目工作簿均从同一逐槽数据源聚合。复现记录只登记文件路径、大小和修改时间，不计算或比较文件哈希，因此不提供密码学完整性保证。

结果解释遵循“数值可行、因果可用、外部有效性待检验”的层次。逐槽残差接近机器精度证明计算结果满足本文方程；未来扰动不影响当前决策说明实现遵守给定信息边界；54组实验和分层诊断说明结论在主要设定变化下如何移动。但这些证据不能自动证明另一年份、另一微网或另一合同条款下仍有同样节约率。工程迁移时应先复现输入映射和结算，再用滚动样本外数据重新校准历史窗口与保守度。

\subsection{模型优点与局限}

本文方法具有四点优点：第一，信息集明确，预测与执行均可通过未来扰动检验；第二，规划层为连续LP，执行层为可逐槽复核的因果规则；第三，联合残差同时保留负荷和光伏误差的同期特征，未聚类正式模式又避免压缩损失；第四，风险模式、信息版本、结算口径、更新集合和设备参数都有真实重算或明确标注的同策略重计费证据。

局限也十分明确。其一，边际分位安全轨迹会丢失跨时段联合概率，不能提供机会约束保证。其二，相似日和历史中位数属于低参数预测，可能无法捕捉节假日、极端天气或结构突变。其三，真实执行采用优先级规则而非全年完美信息优化，设备参数的实际费用可能非单调。其四，储能老化、备用、配网潮流和需求响应不在题设数据中，本文没有虚构这些成本；工程实施时应加入退化成本、网络约束和滚动终端集合。其五，2小时方案是由已发布预报与观测构成的合成短临结果，不能替代对真实高频预报服务的独立评估。
