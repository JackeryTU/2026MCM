# 候选图表

这里保存求解代码生成的全部候选图，是论文配图的权威来源。绘图主代码放在项目根目录的 `问题X_求解.py` 或 `.m`，共用的绘图样式与导出工具放在 `utils/`；本目录只放生成物，不放绘图源码。

## 文件命名

- 原始数据图：`raw_q1_*`、`raw_q2_*` 等。
- 模型运行过程图：`process_q1_*`、`process_q2_*` 等。
- 最终结果图：`result_q1_*`、`result_q2_*` 等。
- 灰度或视觉质检预览：由审计工具自动生成时集中放入 `_qa/`；自行生成时保留与对应图一致的基本名称，并添加明确的 `_gray` 或 `_qa` 后缀。
- 可选汇总页面：`图表面板.html`，其中只能使用可移植的相对路径。

## 格式与数量

- 每张正式候选图同时导出 SVG 与至少 300 DPI PNG。
- 原始数据图、过程图、结果图每类至少 3 张，合计至少 9 张。
- 每个子问题在三类中各至少有 1 张候选图。
- 同一内容的 SVG、PNG 和灰度预览只算 1 张逻辑图。
- 图可以多生成备选，但每张都必须对应明确结论并通过数据、布局和视觉检查。

## 修改与论文使用

- 图片需要修改时，回到根目录的求解／绘图代码调整并重新运行；不得直接修改导出的位图。
- 论文手选定图片后，将已核验版本复制到 `paper/` 中官方 LaTeX 模板约定的图片位置。
- 不使用依赖某台电脑绝对路径或权限的软链接。
- 论文中的图注、数值和统计口径必须与代码输出及 `results/` 一致。
