# 候选图表

## 当前状态（2026-09-11）

本目录已经由修订模型的真实年度结果和 54 组实验重新生成，共 **16 张逻辑图**：16 份可编辑 SVG、16 份 300 DPI PNG，以及 _qa/ 中 16 份等尺寸灰度预览。格式严格检查和 q1/q2/q3/q4 三类图覆盖检查均退出 0；作者已实际查看所有彩色/灰度图。P2 独立验收仍待完成。

权威绘图源为项目根目录 plot_all.py，数据源为 results/，契约见 图表契约-重算版.md。旧契约明确废止。文件名 raw/process/result 分别表示原始数据、过程和结果；每个子问题均具备三类图。

## 使用约定

- 每张图须结合其数据、单位、统计期和契约解释，不能仅据视觉推导因果结论。
- 问题四价格—调度图的相关系数仅为事后描述；实际价格用于现金结算，规划使用因果预测。
- 所有子问题的图都保留 SVG；LaTeX 可使用同源 PNG，不在编译时转换 SVG。
- 修改应回到绘图代码并重跑检查，不直接修改位图。
- 论文资源将复制到独立的 参考初稿-LaTeX/，不改用户已有 paper/。
- 按用户要求，只记录资源路径、大小和修改时间，不计算、不比较哈希。

视觉检查与局限详见 ../reviews/过程归档/01_验收回执/P2作者自检.md。
