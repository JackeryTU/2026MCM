# 当前候选图目录

本目录是项目当前唯一的候选图目录。论文手应从这里选择已经核验的图片，并复制到正式 `paper/` 工程的模板约定位置。

- 当前候选图来自 P2 通过后的编程复现流程。
- 当前活动图件统一放在 `figures/`，不再使用 `figures_versioned/`。
- 当前共 13 张逻辑图：原始数据图 5 张、模型过程图 4 张、最终结果图 4 张。
- 每张逻辑图保留 SVG、PNG 和 `_qa/` 下的灰度质检预览；同一逻辑图的不同格式不重复计数。
- 图件需要调整时应回到绘图代码重新导出，不直接修改 PNG 或 SVG。

`reviews/过程归档/04_独立复现/programmer_v2_p2/` 中的 `figures_versioned/` 属于历史隔离复现证据，不是当前活动图件目录。
