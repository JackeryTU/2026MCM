# 正式论文工作区

这里是论文手实际维护的参赛论文，也是正式正文的唯一权威来源。

## 初始化

1. 获取目标竞赛当届官方 LaTeX 模板。
2. 将模板完整复制到本目录，保留原有 `.tex`、`.cls`、`.sty`、`.bst`、字体和模板图片。
3. 在根目录 `README.md` 填写模板来源和届次。
4. 按官方模板原始结构写作；

## 边界

- `参考初稿-LaTeX/` 和 `参考初稿.pdf` 只供查阅，不能反向覆盖本目录。
- 可人工核对并吸收参考稿中的公式、结果解释和写作思路，但正式文本由论文手自行撰写。
- 论文数值必须与 `results/` 一致，图片必须来自根目录 `figures/` 的已核验版本。
- 论文采用的图片复制到官方模板约定的位置，文件名保持稳定。
- 是否拆分章节由论文手决定；只有协作或维护确有需要时才拆分。
- 不在 `submission/` 中修改论文；所有修改在这里完成并重新编译。

## 本届校内说明中的输出约束

以下内容来自 2026-08-08 校内《赛前准备》，最终仍须与当届全国官网和正式模板核验：

- 论文不设置目录，正文不超过 30 页。
- 参考文献之后另起一页写附录。
- AI 使用声明放在参考文献之前；本队已使用 AI，须如实声明用途，并在支撑材料中提供详细报告。
- 论文 PDF 不包含承诺书和编号专用页。
- 正文、文件名、目录名和 PDF 元数据不得出现学校、队员姓名等身份信息。
- 程序按正式规则放入附录或作必要说明，同时将完整可运行源程序放入支撑材料。
- 正文引用与文末参考文献必须双向对应。
