# 正式论文工作区

这里是论文手未来实际维护的参赛论文，也是正式正文的唯一权威来源。论文手尚未开始正式写作，因此当前目录不含正文、LaTeX 工程或 PDF。根目录的 `参考初稿-正常版-LaTeX/` 与 `参考初稿-详解版-LaTeX/` 只是 AI 辅助参考材料，不能代替本目录中的正式论文。

## 当前状态（2026-09-12）

- 正式论文尚未开始，`paper/` 当前只保留本说明和官方规则检查清单。
- 正常版参考稿为 17 页，详解版参考稿为 21 页；两版 PDF 和源文件均位于根目录的参考初稿位置。
- 参考稿只用于队伍逐式理解、人工改写和复核，不能把其构建通过等同于正式论文完成或规则审核通过。
- 权威结果、冻结图件和验收回执保留在项目约定目录中；旧参考稿与临时产物已移至 `archive/cleanup_20260912/`。
- 用户要求不检测任何哈希，因此本次整理不生成、不填写、不比较 SHA-256 或 MD5。
- 完成正式论文改写后，应从本目录重新编译，并把经过核验的 PDF 与支撑材料复制到 `submission/`。

## 两版参考初稿

| 版本 | 正文 | PDF | 用途 |
|---|---|---|---|
| 正常版 | `../参考初稿-正常版-LaTeX/main.tex` | `../参考初稿-正常版.pdf` | 学术表达简洁，供人工改写参考 |
| 详解版 | `../参考初稿-详解版-LaTeX/main.tex` | `../参考初稿-详解版.pdf` | 逐变量、逐步骤解释模型，便于队伍理解和复核 |

两版参考稿使用 `results/` 的当前权威结果和 `figures/` 的当前核验图件生成；各自工程内的 `figs/` 是参考稿的独立图片副本。正式论文开始后，应由论文手按当前结果重新选择和复制图片。

## 初始化

1. 获取目标竞赛当届官方 LaTeX 模板。
2. 将模板完整复制到本目录，保留原有 `.tex`、`.cls`、`.sty`、`.bst`、字体和模板图片。
3. 在根目录 `README.md` 填写模板来源和届次。
4. 按官方模板原始结构写作；

## 边界

- 根目录的两版参考初稿只供参考，不能反向覆盖本目录。
- 可人工核对历史稿中的公式、结果解释和写作思路，但正式文本只在本目录维护。
- 论文数值必须与 `results/` 一致，图片必须来自根目录 `figures/` 的已核验版本。
- 论文采用的图片复制到官方模板约定的位置，文件名保持稳定。
- 是否拆分章节由论文手决定；只有协作或维护确有需要时才拆分。
- 不在 `submission/` 中修改论文；所有修改在这里完成并重新编译。
