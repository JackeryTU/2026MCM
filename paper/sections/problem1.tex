\subsection{问题分析与模型构建：确定性典型日基准调度场景}
问题一给出完整典型日的负荷、光伏出力和分时电价，调度开始时已知全部数据；储能还需满足日内电量闭环。因此，本题可作为确定性线性规划基准算例，用来检查微网基础模型。模型求解调用SciPy提供的线性规划工具\cite{virtanen2020scipy}。

在通用微网物理模型基础上，本题关闭应急购电$u_t=0$和闲置弃购量$w_t=0$，并施加储能日闭环约束 $S_1=S_{145}=6000\ \mathrm{kWh}$（$S_t$为$t$时段末储能荷电量）。功率平衡与储能状态递推约束如下：
\begin{align}
g_t + v_t + y_t &= L_t + x_t, \label{eq:q1balance}\\
S_{t+1} &= S_t + 0.9x_t - \frac{y_t}{0.9}, \label{eq:q1soc}\\
0 \le v_t \le V_t,\quad 0 \le x_t,y_t &\le B_{\max}, \label{eq:q1bound1}\\
1200 \le S_t &\le 10800. \label{eq:q1bound2}
\end{align}
式中：$g_t$为$t$时段电网购电量；$v_t$为本时段光伏出力；$y_t$为储能放电电量；$L_t$为负荷电量；$x_t$为储能充电电量；$V_t$为光伏最大可用出力。

模型主目标为最小化全天购电费用：
\begin{equation}
\min \quad \sum_{t=1}^{144} c_t\, g_t.
\label{eq:q1main}
\end{equation}
其中$c_t$代表$t$时段购电单价。

仅以费用作为目标时，最优解集合内可能出现无物理意义的微小同时充放电数值解。为此采用两阶段优化策略：第一步求解得到最优理论费用$f^*$；第二步在总购电费用不超过$f^*+\varepsilon$（$\varepsilon=10^{-4}$元）的约束下，以最小化储能充放电总量作为次级目标：
\begin{equation}
\min \quad \sum_{t=1}^{144}(x_t+y_t) \quad \text{s.t.}\quad \sum_{t=1}^{144} c_t g_t \le f^*+\varepsilon.
\label{eq:q1sub}
\end{equation}
两级问题均为线性规划，求解器可分别给出全局最优解。

\noindent\textbf{命题 1（连续LP松弛的可行性）}　在电价非负、微网不可售电、无充放电补贴且充放电效率不超过1的条件下，费用最优解集合中必存在一个不同时充、放电的解。因此，无须在基础模型中引入充放电0--1互斥变量。

\noindent\textbf{证明}　若某费用最优解在时段$t$满足$x_t>0,y_t>0$，取充分小的$\delta>0$，令$x'_t=x_t-\delta/\eta_c$、$y'_t=y_t-\delta\eta_d$。则储能变化量不变；因$\eta_c\eta_d\le1$，功率平衡所需的外购电量不增加，费用也不增加。重复该操作，直至$x_t=0$或$y_t=0$，即可得到同样费用且不同时充、放电的可行解。逐时段处理即得结论；第二阶段的充放电总量最小化仅用于选取这一类数值解。证毕。

命题 1 的证明不依赖问题一的具体场景，只要求外购电量以正单价线性计入目标函数且为自由变量。因此，它也适用于问题二至四的日前规划层（将$g_t$替换为$p_t$或$q_t$）；执行层的合同费用已确定、$u_t$显式定价，则由命题 3 单独处理。

调度结果体现储能低电价充电、高电价放电的套利特性：凌晨低电价时段购电并给储能充电；光伏大发时段依靠光伏出力供给负荷，部分时段购电量降至0；晚高峰电价抬升时，储能集中放电，降低高价时段购电需求。全天总充电量20740.66 kWh，总放电量16799.94 kWh，光伏全部就地消纳，无弃光。

逐时段功率平衡与SOC递推残差处于$10^{-13}$量级，属于求解器浮点计算误差范围；储能荷电量全程保持在安全区间内，并满足日初--日末SOC闭环约束。这说明基础微网模型满足预期约束，可作为问题二至四不确定性调度的基准。
