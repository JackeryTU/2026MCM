# 2026 全国规则交付检查清单

依据：全国大学生数学建模竞赛组委会公开的 2026 年修订稿/试行规定。提交前仍需再次打开官网核验是否有更新，并检查所在赛区额外要求。

## 论文格式

- [ ] A4。
- [ ] 上下左右页边距均至少 2.5 cm。
- [ ] 电子版论文不含承诺书和编号专用页。
- [ ] 电子版第一页直接为摘要页。
- [ ] 摘要含题目、摘要正文、关键词，原则上不超过一页。
- [ ] 从摘要页开始用阿拉伯数字连续编号，摘要页为第 1 页。
- [ ] 页码位于页脚中部。
- [ ] 正文不要目录。
- [ ] 正文不超过 30 页。
- [ ] 附录页数不限。
- [ ] 摘要、正文、附录不得出现参赛者身份、学校和赛区信息。
- [ ] 所有公开/外部资料均在正文引用处标注并列入参考文献。
- [ ] 电子论文为单独 PDF/Word，建议 PDF，不超过 20 MB。

## 附录 / 支撑材料

- [ ] 附录列出支撑材料文件清单。
- [ ] 附录包含建模所用全部完整、可运行源程序代码。
- [ ] 若没有使用程序，明确写“本论文没有用到程序”。
- [ ] 支撑材料含所有必要源程序、自主查阅使用的数据（赛题原始数据除外）、必要的大篇幅中间结果图表等。
- [ ] 支撑材料压缩成 RAR 或 ZIP，不超过 20 MB。
- [ ] 若确实没有支撑材料，在附录明确写“本论文没有支撑材料”。
- [ ] 支撑材料与论文内容一致，且不含身份/学校/赛区信息。

## AI 工具

- [ ] 参考文献之前存在“AI工具使用声明”。
- [ ] 未使用 AI 时采用未使用声明。
- [ ] 使用 AI 时采用使用声明，并写明简要用途。
- [ ] 使用 AI 时，支撑材料中包含 `AI工具使用详情.pdf`。
- [ ] 详情记录工具名称、版本/模型、具体目的和阶段、主要提示方式/使用过程。
- [ ] 除语言润色外，记录主要 AI 输出的采纳、人工修改和核验。
- [ ] 核心建模和分析由参赛队主导，AI 生成内容逐项人工审核、验证。
