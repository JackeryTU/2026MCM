## 解释边界

- q2→q3 的差异同时包含预测信息及更新规则变化，不能全归于更新次数。纯更新频率比较见 experiments 中相同零时信息的 0/12/6/2 小时方案。
- 2 小时方案使用因果合成短临更新，不是附件提供的额外官方预报。
- 替代结算式仅对同策略重新计费，不是按替代规则重新优化。
- 核心方法是边际分位轨迹压缩后的线性规划，不宣称为完整随机 MPC 或具有形式化概率保障。
- 附件和官方模板只读；结果表保留模板表头，按自然时间槽位置写入，时间偏移口径见模型文档。
