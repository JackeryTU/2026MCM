# 2026MCM-C 项目收尾说明

更新日期：2026-09-11。

## 目录职责

本项目按根目录 `README.md` 整理：

- `data/`：题目和原始附件，只读。
- `题目分析报告.md`、`术语表格.md`：建模阶段权威说明。
- 根目录 `.py`：主要求解、复现、实验和绘图入口；`utils/` 保存复用工具。
- `results/`：程序生成的权威数值结果；`figures/`：候选图和灰度质检图。
- `参考初稿-LaTeX/`、`参考初稿.pdf`、`参考初稿.build.json`：Skill 生成的参考论文工程、PDF 和构建记录，不是正式参赛论文。
- `paper/`：正式论文唯一权威来源；当前尚未放入队伍人工改写后的正式论文。
- `reviews/`：根层只保留 `README.md` 作为索引；规则核验、M1/P1/P2/W1/W2 回执、渲染抽检、独立复现和解压副本统一归档在 `reviews/过程归档/`，不参与程序运行。
- `submission/`：只接收从 `paper/` 重新编译并核验的正式冻结文件；当前不放参考稿。
- `checkpoints/Checkpoint-V1/`：可回退的参考稿检查点。
