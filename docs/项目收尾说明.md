# 2026MCM-C 项目收尾说明

更新日期：2026-09-12。

## 目录职责

本项目按根目录 `README.md` 整理：

- `data/`：题目和原始附件，只读。
- `题目分析报告.md`、`术语表格.md`：建模阶段权威说明。
- 根目录 `.py`：主要求解、复现、实验和绘图入口；`utils/` 保存复用工具。
- `results/`：程序生成的权威数值结果；`figures/`：候选图和灰度质检图。
- `paper/`：论文手未来正式写作的唯一工作区，目前没有论文正文。
- `参考初稿-正常版-LaTeX/`、`参考初稿-详解版-LaTeX/` 及根目录 PDF：两版 AI 辅助参考初稿，正常版 17 页、详解版 21 页，不能直接提交。
- `reviews/`：根层保留索引和 `论文修改意见.md`；规则核验、M1/P1/P2/W1/W2 回执、渲染抽检、独立复现和解压副本统一归档在 `reviews/过程归档/`，不参与程序运行。
- `submission/`：只接收从 `paper/` 重新编译并核验的正式冻结文件；当前不放参考稿。
- `archive/cleanup_20260912/`：已退出活动工作区的旧参考稿、旧检查点、临时渲染、重复复现／解压副本及 smoke 结果；需要时可按原相对路径恢复。
