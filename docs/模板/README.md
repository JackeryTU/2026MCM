## 使用原则

1. 先完成建模与编程，再根据真实模型、代码和结果撰写论文。
2. 示例、阈值和 Prompt 只能按题目改写，不能脱离实际数据直接套用。
3. 所有涉及竞赛年份、格式限制、AI 使用和提交要求的内容，以当届官方规则为准。
