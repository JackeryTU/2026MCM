## 一、论文整体架构（八段式）

| 序号 | 章节 | 字数 | 一句话要点 |
|------|------|------|------------|
| 摘要 | 摘要 | 600-900字/一页 | 六段法，每段有加粗数字 |
| 一 | 问题重述 | 400-600字 | 不照抄原题，四问转化表 |
| 二 | 问题分析 | 800-1200字 | 论"为什么选这方法"，技术路线图 |
| 三 | 模型假设 | 200-400字 | 5-8条，每条有依据 |
| 四 | 符号说明 | 1页表格 | 三线表，无竖线 |
| 五 | 模型建立与求解 | 7000-9000字 | 核心章节，每问题四小节 |

| 七 | 模型评价与推广 | 600-900字 | 优点/缺点/推广三段式 |
| — | AI使用声明 | — | 正文后、参考文献前 |
| 八 | 参考文献 | — | GB/T 7714，5-15篇 |
| — | 附录 | 不限 | 代码+完整数据表 |

> 一级标题用中文数字：一、二、三、（国赛硬性要求）

## 二、摘要六段法（每段怎么写）

### 标题格式
```
居中、加粗、三号字：「摘  要」（两字间空两格）
```

### 六段结构与填空模板

**第1段·背景+总方法**（80-120字）
```
针对【研究背景】中【核心难点1】、【核心难点2】等问题，本文建立了
以【核心模型】为核心、融合【辅助方法1】与【辅助方法2】的【框架类型】框架。
```

**第2段·问题一**（100-150字）
```
针对问题一，【方法】，构建了以【目标】为目标的【模型类型】模型，
包含【约束1】、【约束2】和【约束3】三类约束。调用【求解器】求解
得到最优【指标】为【加粗数字】。
```

**第3段·问题二**（100-150字）
```
针对问题二，【新增约束】，修正了【关键方程】。重新求解后，
得到【指标】为【加粗数字】，较问题一【上升/下降】【加粗百分比】%。
```

**第4段·问题三**（100-150字）
```
针对问题三，针对【规模特征】，设计了【双层/分层】框架：
外层【方法】搜索【变量】，内层【方法】计算【目标】。
求得【结果】为【加粗数字】。
```

**第5段·问题四**（100-150字）
```
针对问题四，引入【预测/分布模型】对【数据】拟合（μ=【均值】，σ=【标准差】），
通过【N】次蒙特卡洛模拟验证，【指标】满足【约束】。
```

**第6段·总结**（50-80字）
```
本文模型具有【普适性/扩展性】，对【实际场景】具有指导意义。
```

### 三条硬性要求
1. 每段开头必须"针对..."领起
2. 第2-5段每段至少一个**加粗数字结果**
3. 方法名必须出现（MILP/ARIMA/TOPSIS/K-means/ANOVA/ODE等）

### 关键词
5个，按"方法→对象→目标"排列：
```
关键词：混合整数线性规划；遗传算法；蒙特卡洛模拟；生产排程；鲁棒优化
```

## 三、模型建立四小节结构（每个问题下）

| 小节 | 标题 | 字数 | 核心内容 |
|------|------|------|----------|
| 1 | 模型目标/变量关系 | 100-200字 | 目标函数或变量间关系 |
| 2 | 约束条件/模型方程 | 400-800字 | 每条配公式+文字解释+编号 |
| 3 | 求解算法 | 200-400字 | 算法步骤+求解器参数 |
| 4 | 求解结果 | 200-400字 | 加粗数字+图表+合理性分析 |

> 顺序不能乱：目标→约束→算法→结果

## 四、六大题型速查

| 题型 | 文件夹 | 默认方法 | 摘要必报数字 |
|------|--------|----------|--------------|

## 五、比赛三天使用流程

### 拿到题目（Day1上午）
1. 打开本文件 → 确认八段式架构
2. 判定题型 → 打开对应 `02-07` 题型文件夹
3. 看 `问题分析要点.md` 选方法
4. 打开本目录的 `数学建模论文通用LaTeX模板.tex` 开始套模板

### 写摘要（Day3上午，最后写）
1. 打开本文件 → 看六段法填空模板
2. 打开对应题型文件夹的 `摘要范例.md` 参考写法
3. 填入每段的方法名+加粗数字
4. 详细规范见 `../通用写作规范/摘要六段法通用规范.md`

### 排版编译（Day3下午）
1. 打开本目录的 `LaTeX排版规则.md` 查编译错误
2. 三线表无竖线、图下表上、公式编号

### 提交前（Day3晚）
1. 打开 `../通用写作规范/提交前检查清单.md` 逐项勾选
2. 确认AI声明位置（正文后、参考文献前）→ 见 `AI使用规范.txt`

## 六、五条铁律速记

1. **先结果后论文**：先跑通最小模型拿数字，再写论文
2. **保证能解**：优先用有求解器的方法，启发式先拿可行解
3. **警惕极端值**：建模前做描述性统计+箱线图
4. **参数合理**：每个参数有来源（题目/文献/假设+灵敏度）
5. **摘要六段法**：每段有方法名+加粗数字，不空话
