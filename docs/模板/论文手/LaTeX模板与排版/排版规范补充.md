# 排版规范补充

> 从原总指南拆出的页面、字体、标题、图表、公式、页眉页脚、代码、参考文献和 AI 声明排版补充。
> 涉及特定竞赛、届次或所谓“官方”“硬性”要求的内容，使用前必须以当届官方规则核验。

## 五、排版规则：从 LaTeX 到细节的红线

### 5.1 全局页面设置

```latex
\documentclass[12pt,a4paper,fontset=fandol]{ctexart}
\usepackage{geometry}
\geometry{left=2.5cm, right=2.5cm, top=2.5cm, bottom=2.5cm}
\renewcommand{\baselinestretch}{1.5}     % 1.5 倍行距
\setlength{\parskip}{0.5em}              % 段间距
\setlength{\parindent}{2em}              % 首行缩进 2 字符
```

**避坑**：`fontset=fandol` 使用内置字库，避免 `FangSong.otf` 找不到的报错。

### 5.2 字体设置

```latex
\usepackage{newtxtext}                   % 正文英文 Times 风格
\usepackage{newtxmath}                   % 数学公式 Times 风格
```

**要求**：正文中文宋体、英文 Times New Roman；数学公式所有变量斜体。

### 5.3 章节标题格式

```latex
\ctexset{
    section/name={,},
    section/number=\chinese{section}、,           % 一、二、三、
    section/format=\large\bfseries\centering,      % 居中加粗
    subsection/format=\bfseries,                   % 二级加粗
    subsubsection/format=\itshape                  % 三级斜体
}
```

**章节编号样式**：一级"一、二、三、"，二级"1.1 1.2"，三级"1.1.1"。

### 5.4 图表规范

#### 5.4.1 图规范
- **图题在图下方居中**：`图 4.1 不同代际群体的媒介使用时长对比`。
- 编号格式：`图 [章节号].[序号]`，如 `图 3.2`。
- 图片宽度建议 `0.9\textwidth` 或 `0.95\textwidth`。
- 必须加 `\label{fig:xxx}` 便于交叉引用。
- **图下方加 footnotesize 注释**，解释图中关键信息（评委很看重）。

```latex
\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{figures/fig6_gantt.png}
    \caption{七天最优生产计划甘特图}
    \label{fig:gantt}
    \begin{center}
        \footnotesize 本图是问题一 MILP 模型求得的最优生产排程可视化结果。
        横轴为周一至周日，纵轴为各组件，色块表示该日安排生产。
    \end{center}
\end{figure}
```

#### 5.4.2 表规范
- **表题在表上方居中**：`表 4.3 各类评价指标的灵敏度分析结果`。
- **必须用三线表**（booktabs）：`\toprule` `\midrule` `\bottomrule`。
- **禁止纵向竖线**。
- 行距用 `\renewcommand{\arraystretch}{1.3}` 调宽。

```latex
\begin{table}[H]
    \centering
    \renewcommand{\arraystretch}{1.4}
    \caption{主要符号及其含义}
    \begin{tabular}{cll}
        \toprule
        符号 & 意义说明 & 单位 \\
        \midrule
        $x_{i,t}$ & 决策变量，第$t$天组件$i$的生产数量 & 件 \\
        $y_{i,t}$ & 0-1变量，第$t$天是否生产组件$i$ & — \\
        \bottomrule
    \end{tabular}
\end{table}
```

### 5.5 公式规范

- 每个独立公式用 `\begin{equation} \label{eq:xxx}`，自动编号。
- 公式内变量斜体，函数名（sin、log、max）正体。
- 引用公式用 `\eqref{eq:xxx}` 或"式 (1)"。

```latex
\begin{equation}
\min F = \sum_{i \in N} \sum_{t=1}^{7} \left( H_i \cdot z_{i,t} + S_i \cdot y_{i,t} \right)
\label{eq:obj1}
\end{equation}
```


### 5.7 页眉页脚

```latex
\pagestyle{fancy}
\fancyhf{}                            % 清空默认
\fancyfoot[C]{\thepage}               % 页脚居中显示页码
\renewcommand{\headrulewidth}{0pt}    % 不画页眉横线
```

### 5.8 代码块设置

```latex
\usepackage{listings}
\usepackage{xcolor}
\lstset{
    language=Python,
    basicstyle=\small\ttfamily,
    keywordstyle=\color{blue},
    commentstyle=\color{green!60},
    stringstyle=\color{red},
    numbers=left,
    numberstyle=\tiny\color{gray},
    frame=single,
    breaklines=true,                   % 自动换行防溢出
    tabsize=4,
    literate={_}{{\_}}1,               % 修复下划线 Missing $ 报错
    showstringspaces=false,
    captionpos=b                       % 代码标题在下方
}
```

### 5.10 2026 国赛 AI 使用规范（必读）

> 本节源自 `论文撰写模板与规范/AI使用规范.txt`（2026 高教社杯试行版）。

**核心变化**：
- ❌ 旧规（2025 及以前）：AI 使用记录写在参考文献中。**已作废**。
- ✅ 新规（2026 试行）：单独增设 **AI 工具使用声明**板块，位置固定在**正文之后、参考文献之前**，配套专属附件。

**二选一填写**：
- 未使用 AI：直接如实声明。
- 已使用 AI：标注使用场景、用途、人工核验情况，附 1~3 次典型交互记录。

**AIDC 阈值**：
- < 20%：可正常填报"未使用 AI"。
- > 20% 且瞒报：取消本年度评奖评优资格。

**硬规则**：
1. AI 是辅助工具，非刚需（可用可不用）。
2. 禁止照搬 AI 答案，所有 AI 内容必须逐项人工核实。
3. AI 范围覆盖：大语言模型、生成式 AI、代码辅助工具、数模专属智能体。

**声明模板**（置于参考文献前）：
```
AI 工具使用声明

本队伍在本次竞赛中 [未使用 / 使用了] AI 工具。

[若使用]：
- 工具名称与版本：XXX
- 使用场景：语言润色 / 代码调试 / 模型思路梳理 / 数据整理
- 典型交互实例：（附 1~3 次核心交互记录）
- 人工修改与核验说明：（描述对 AI 输出的核对、修正、优化过程）
```
