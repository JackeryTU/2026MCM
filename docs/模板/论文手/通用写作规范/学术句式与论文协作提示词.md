# 学术句式与论文协作提示词

> 从原总指南拆出的学术句式以及论文撰写、摘要、图表插入、润色和 AI 声明提示词；提示词中的规则须按实际任务修订。
> 涉及特定竞赛、届次或所谓“官方”“硬性”要求的内容，使用前必须以当届官方规则核验。

## 六、话术库：可直接套用的学术句式

> 本节是"句式弹药库"，写论文卡壳时直接套用，避免口语化。

### 6.1 问题重述句式

- "本题要求为 [对象] 制定 [目标] 方案。[对象] 具有 [特征 1]、[特征 2] 等复杂性。"
- "核心任务是在满足 [约束] 的条件下，建立 [模型类型]，求解使 [目标] 最优的 [方案]。"
- "具体分为 [N] 个递进问题：问题一要求 [基础]；问题二引入 [新约束]；问题三扩展至 [更大规模]；问题四引入 [随机性]。"

### 6.2 问题分析句式

- "针对本问题的 [特征]，若采用 [常规方法]，会面临 [困难]。因此本文采用 [方法]，因为 [理由]。"
- "鉴于本问题的所有约束均为 [线性/非线性] 形式，且目标函数 [性质]，本文采用 [方法] 作为求解方法。"
- "相比 [方法 A]，[方法 B] 具有 [优势 1]、[优势 2]、[优势 3] 三大优势。"

### 6.3 模型假设句式

- "为了简化模型并聚焦于核心问题，我们做出以下合理假设："
- "假设 [对象] [行为/性质]，与 [实际场景] 一致。"
- "假设不考虑 [因素]，因为 [理由]（如该因素在 [时间尺度] 内影响可忽略）。"

### 6.4 模型建立句式

- "令 $x_{i,t}$ 表示 [含义]，$y_{i,t}$ 表示 [含义]，建立如下 [模型类型]："
- "以 [目标] 为目标，目标函数为："
- "其中第一项为 [含义]，第二项为 [含义]。"
- "约束条件如下："
- "该约束表明：[文字解释]，即 [通俗解释]。"

### 6.5 约束解释句式

- "（1）库存平衡约束：[公式]。其中 $P_i$ 为 [集合]，该约束表明 [含义]。"
- "（2）产能上限约束：[公式]。只有 [对象] 占用 [资源]，[其他] 不占用。"
- "（3）生产状态逻辑约束（大 M 法）：[公式]。当 $y=0$ 时强制 $x=0$；当 $y=1$ 时 $x$ 可取任意非负值。"
- "（4）初始与终止约束：[公式]。"

### 6.6 求解结果句式

- "求解结果显示，问题 [N] 的最优 [指标] 为 **[数值]**，其中 [分量 1] = [数值]，[分量 2] = [数值]。"
- "由表 [N] 可见，方案 [k] 的 [指标] 比方案 [j] [低/高] 了 [百分比]%，这主要是因为 [原因]。"
- "如图 [N] 所示，[趋势描述]，说明 [结论]。"
- "该结果 [符合/略低于/优于] 题目要求，验证了模型的 [有效性/准确性]。"

### 6.7 灵敏度分析句式

- "为了进一步验证模型在参数扰动下的稳定性，我们对核心参数 [X] 进行了灵敏度分析。"
- "结果显示，当 [X] 变化 [±20%] 时，目标函数仅变化 [1.2%]，说明模型具有 [极强/较好] 的稳定性。"
- "由图 [N] 可见，[指标] 对 [参数] [敏感/不敏感]，这是因为 [机理]。"

### 6.8 模型评价句式

- **优点**：
  - "模型具有 [普适性/可扩展性]，可推广至 [其他场景]。"
  - "算法 [收敛快/复杂度低]，在 [规模] 下 [秒级] 求解。"
  - "约束考虑 [全面/贴合实际]，包含 [约束 1]、[约束 2] 等。"
- **缺点**：
  - "忽略了 [因素]，可能导致 [结果偏差方向]。"
  - "部分参数（如 [参数]）依赖 [主观估计/题目给定]，实际场景需 [重新标定]。"
- **推广**：
  - "可尝试用 [方法 A] 代替 [方法 B]，以 [改善方向]。"
  - "可引入 [更复杂约束/随机因素]，使模型更贴近 [实际]。"

### 6.9 摘要句式

- "针对 [背景] 中 [难点] 等问题，本文建立了以 [核心模型] 为核心、融合 [辅助方法] 的 [框架类型]。"
- "针对问题 [N]，[方法]，构建了以 [目标] 为目标的 [模型类型]，包含 [约束 1]、[约束 2] 三类约束。调用 [求解器] 求解得到 [指标] 为 **[数值]**。"
- "针对问题 [N]，[新增约束]，修正了 [关键方程]。重新求解后，得到 [指标] 为 **[数值]**，较问题 [N-1] [上升/下降] [百分比]%。"
- "通过 [N] 次 [模拟/检验] 验证，[指标] 满足 [约束]。"
- "本文模型具有 [优点]，对 [实际场景] 具有指导意义。"

### 6.10 通俗解释句式（非专业评委可读）

- "MILP：通俗解释为'在一组线性约束下寻找最优整数解的数学方法'。"
- "遗传算法：通俗解释为'模仿自然进化，通过选择-交叉-变异逼近最优解'。"
- "蒙特卡洛模拟：通俗解释为'随机生成上万种场景逐一检验，统计满足率'。"
- "安全提前期：通俗解释为'组件必须提前一天生产入库，第二天才能用于装配'。"

## 七、提示词库：AI 协作的可复用 Prompt

> 本节源自 `题目与思路/复用提示词-数学建模论文优化.md`，经 2022B 题实战验证。每个 Prompt 都是"开箱即用"的指令模板，直接复制给 AI 即可。

### 7.1 论文撰写启动 Prompt

```
你是数学建模竞赛论文撰写专家。请根据项目目录中的题目文件和求解代码，
撰写一篇完整的数学建模论文（LaTeX 格式）。

要求：
1. 包含完整结构：摘要、问题重述、问题分析、模型假设、符号说明、模型建立、
   模型求解、结果分析、模型评价、参考文献、附录
2. 所有数值结果必须来自实际代码运行，不得估算
3. 图表必须使用真实求解数据生成
4. 论文风格严谨但易懂，非本专业评委也能理解
5. 代码附录应使用实际编程语言（非伪代码）
6. 每个关键概念首次出现时给出通俗解释
7. 摘要采用四段法，每段必须包含具体数值结果
```

### 7.2 摘要优化 Prompt

```
请按照"摘要四段法"优化论文摘要：

结构要求：
- 第一段（80~120 字）：背景 + 总方法 + 解决的问题类型
- 第二段（100~150 字）：问题一方法 + 具体数值结果
- 第三段（100~150 字）：问题二方法 + 具体数值结果
- 第四段（150~200 字）：问题三/四方法 + 具体数值结果
- 末段（50~80 字）：模型优点 + 实际指导意义

硬规矩：
1. 每段必须出现至少 1 个具体数字
2. 禁止"采用 XX 模型然后用软件计算"，必须写"算出了 [具体值]"
3. 关键词 5 个左右，加粗，置于末尾
4. 总字数控制在 600~800 字，单独成页

请输出优化后的摘要 LaTeX 代码。
```

### 7.3 图表生成与插入 Prompt

```
请检查论文中所有图表，确保：
1. 甘特图使用 MILP 求解器输出的真实生产计划数据，而非估算值
2. 收敛曲线的纵轴范围和最终收敛值与实际求解结果一致
3. 蒙特卡洛模拟图的均值线与实际统计值匹配
4. 流程图/技术路线图的箭头方向清晰、连接点正确
5. 所有图表保存为 300dpi 高清 PNG，路径在 figures/ 文件夹下
6. 图题在图下方居中，表题在表上方居中
7. 图下方加 footnotesize 注释解释关键信息
8. 在论文 .tex 中用 \includegraphics 正确引用，添加图题和标签
```


### 7.9 论文润色 Prompt（非专业评委可读性）

```
请润色论文表达，确保非 [专业领域] 的评委也能理解：

1. 关键概念添加"通俗理解"注解：
   - [术语 1]：通俗解释为"..."
   - [术语 2]：通俗解释为"..."

2. 公式后添加文字解释，说明每个变量的物理含义

3. [结构/层次]用层次图直观展示（如 BOM 树、决策树）

4. 避免使用未解释的缩写（如 MILP、GA、ARIMA 首次出现时给出全称）

5. 数值结果用表格汇总，关键数字加粗

6. 检查并修正：
   - 口语化表达 → 学术表达
   - 长句拆短，每句一个意思
   - 被动语态优先（"本文建立了"优于"我们建立了"）
```


### 7.11 AI 使用声明生成 Prompt（2026 新规）

```
根据 2026 高教社杯国赛 AI 使用试行规范，生成本论文的 AI 使用声明：

要求：
1. 位置：正文之后、参考文献之前
2. 二选一填写：未使用 AI / 已使用 AI
3. 若已使用，标注：
   - AI 工具名称与版本
   - 使用场景（语言润色/代码调试/模型思路/数据整理）
   - 典型交互实例（1~3 次，无需全部对话记录）
   - 人工修改与核验说明
4. AIDC < 20% 可填报"未使用"
5. 严禁照搬 AI 内容，所有 AI 输出必须人工核验

请生成声明文本。
```
