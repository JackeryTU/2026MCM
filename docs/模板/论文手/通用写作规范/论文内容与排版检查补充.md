# 论文内容与排版检查补充

> 从原总指南拆出的结构、语言和排版检查项。
> 涉及特定竞赛、届次或所谓“官方”“硬性”要求的内容，使用前必须以当届官方规则核验。

### 8.5 结构完整性检查

- [ ] 八大章节齐全（重述/分析/假设/符号/建模/检验/评价/文献）
- [ ] 每个子问题都有"目标函数+约束+算法+结果"四小节
- [ ] 摘要单独成页，含 5 个关键词
- [ ] 参考文献格式 GB/T 7714，方括号序号
- [ ] 附录含完整可运行代码
- [ ] AI 使用声明（2026 新规）置于参考文献前

### 8.6 语言可读性检查

- [ ] 关键概念首次出现有通俗解释
- [ ] 缩写首次出现给出全称（MILP、GA、ARIMA）
- [ ] 无口语化表达（"我们觉得"→"本文认为"）
- [ ] 无未解释的术语
- [ ] 长句已拆短，每句一个意思
- [ ] 被动语态优先

### 8.7 排版细节检查

- [ ] LaTeX 编译无 error（warning 可酌情忽略）
- [ ] 页眉页脚正确（页脚居中页码，无页眉横线）
- [ ] 行距 1.5，段间距 0.5em，首行缩进 2em
- [ ] 章节标题居中加粗（一级）、加粗（二级）、斜体（三级）
- [ ] 无大片空白（图与文字间距合理）
- [ ] 公式未溢出页面
- [ ] 代码块自动换行无溢出
