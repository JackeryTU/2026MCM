本目录只收录论文表达、章节组织和成稿检查资料。模型选择、算法实现、数值验证与代码检查请到 [建模与编程手](../../建模与编程手/)；跨角色的复盘和最终交付检查请到 [公共流程资料](../../公共流程资料/)。

> 涉及具体年份、竞赛以及“官方”“硬性”等表述时，必须以当届官方规则为准。

## 建议使用顺序

1. 先由建模与编程手完成题意分析、模型设计、程序求解和结果验证。
2. 论文手依据本目录资料组织结构，写问题重述、摘要、正文和评价推广。
3. 使用 LaTeX 模板统一排版，并完成论文内容与排版检查。
4. 最后到公共流程资料执行跨角色综合检查和文件交付检查。
