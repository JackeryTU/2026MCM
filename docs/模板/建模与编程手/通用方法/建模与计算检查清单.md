# 建模与计算检查清单

> 从原总指南拆出的数值、数学、结果、图表和代码检查项；阈值必须按题目、数据或文献重新确定。
> 涉及特定竞赛、届次或所谓“官方”“硬性”要求的内容，使用前必须以当届官方规则核验。

### 8.1 数值一致性检查

- [ ] 摘要中的每一个数字与正文/代码结果 100% 一致
- [ ] 正文中的数字与 `results_final.json` 一致
- [ ] 图表中的数字（坐标轴、标签、表格）与正文一致
- [ ] 答案文档（如有）与论文结果一致
- [ ] 关键数字已加粗（用 `\textbf{}`）

### 8.2 数学正确性检查

- [ ] 库存平衡方程时间下标正确（提前期：`x_{i,t-1}` 而非 `x_{i,t}`）
- [ ] 所有约束完整（产能、库存非负、逻辑大 M、边界条件）
- [ ] 目标函数无遗漏成本项
- [ ] 大 M 值合理（= 需求的 2 倍，不要设 50000）
- [ ] 公式编号连续无重复
- [ ] 公式内变量斜体，函数名（sin/log/max）正体

### 8.3 结果合理性检查

- [ ] 交付率类指标不为 100%（随机场景下不可能）
- [ ] 拟合优度 $R^2$ 在合理区间（0.7~0.99，过高要警惕过拟合）
- [ ] 灵敏度分析结果合理（参数变化 ±20% 时目标函数不应剧烈跳变）
- [ ] 多次运行结果稳定（均值 ± 标准差可接受）
- [ ] 收敛曲线确实收敛（不是一直在下降）

### 8.4 图表规范检查

- [ ] 图题在图下方居中，表题在表上方居中
- [ ] 所有表格为三线表（无纵向竖线）
- [ ] 图表编号连续（图 3.1、3.2；表 3.1、3.2）
- [ ] 每张图/表后有一段文字解读
- [ ] 图片 300 dpi 以上，字体 Times New Roman
- [ ] 流程图箭头方向清晰、连接点正确
- [ ] 甘特图数据来自求解器输出（非估算）
- [ ] 图下方有 footnotesize 注释


### 8.8 代码附录检查

- [ ] 代码语言与实际使用一致（Python 非 MATLAB，除非真用 MATLAB）
- [ ] 代码可独立运行（数据定义完整、import 齐全）
- [ ] 关键注释清晰（每段功能有注释）
- [ ] 代码与正文方法描述一致
- [ ] 下划线报错已修复（`literate={_}{{\_}}1`）
