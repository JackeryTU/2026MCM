### 5.6 matplotlib 出图规范

基于 2022B 题 `generate_figures.py` 的实战配置：

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# 全局字体设置
plt.rcParams['font.family'] = 'Times New Roman'
plt.rcParams['mathtext.fontset'] = 'stix'           # 数学字体配套
plt.rcParams['axes.unicode_minus'] = False
plt.rcParams['font.size'] = 11
plt.rcParams['axes.labelsize'] = 12
plt.rcParams['axes.titlesize'] = 13
plt.rcParams['xtick.labelsize'] = 10
plt.rcParams['ytick.labelsize'] = 10
plt.rcParams['legend.fontsize'] = 10

# 学术风格：去顶右边框，刻度向内
plt.rcParams['axes.spines.top'] = False
plt.rcParams['axes.spines.right'] = False
plt.rcParams['xtick.direction'] = 'in'
plt.rcParams['ytick.direction'] = 'in'

fig, ax = plt.subplots(figsize=(7, 4.5), dpi=300)
# ...绘图代码...
plt.tight_layout()
plt.savefig('figures/fig1_framework.png', dpi=300, bbox_inches='tight')
plt.savefig('figures/fig1_framework.pdf', bbox_inches='tight')   # 矢量备份
```

**硬要求**：
- 300 dpi 起步。
- 字体 Times New Roman（中文用 SimSun 或 STSong）。
- 去掉默认顶/右边框，刻度向内。
- 配色用 ColorBrewer 或 seaborn 默认，黑白打印也要可读。

### 7.7 降维分解策略 Prompt（大规模 MILP）

```
当问题规模过大（如 [N] 天 + [M] 个 [决策变量] + 多 0-1 变量）导致 Gurobi
无法直接求解时，采用"降维分解"策略：

### 双层嵌套结构：
- 外层：遗传算法(GA)搜索 [决策变量] 组合，约束 [间距/位置约束]
- 内层：将 [总周期] 按 [切分点] 切分为 [K] 段，每段 ≤ [阈值]，独立调用 MILP 求解
- 段间衔接：前一段期末库存 = 后一段期初库存
- [特殊日] 当天产能强制设为 0
- 总成本 = [K] 段成本之和

### 关键注意事项：
1. "保证能解出来"比"追求绝对最优"更重要
2. big-M 值不要设太大（如 50000），会导致子组件产量异常，设为需求的 2 倍即可
3. 分段时首段不能太长（≤25 天），否则单段 MILP 也会超时
4. PuLP 的 LpVariable.dicts 不支持字典作为 upBound，需循环单独创建变量
```

### 7.8 蒙特卡洛模拟修正 Prompt（交付率验证）

```
请检查蒙特卡洛模拟代码，确保模拟逻辑正确：

### 常见错误（导致交付率虚高）：
1. 错误：plan = mu + ss（每天生产量=均值+安全库存，过于乐观）
2. 错误：if plan * 7 >= sum(dem)（周交付率只比较总量，忽略日时序缺货）
3. 错误：日交付率和周交付率都为 100%（随机需求下不可能）

### 正确逻辑：
1. 初始库存 = 安全库存 ss
2. 每天生产量 = 均值需求 mu（不是 mu+ss）
3. 逐日时序模拟：inventory += mu → 检查 inventory >= dem[t] → 扣减或清零
4. 缺货后库存清零，导致后续日子更容易缺货（连锁效应）
5. 日交付率 = 满足天数 / (N_SIM × 7)
6. 周交付率 = 7 天全部满足的次数 / N_SIM

### 安全库存自动调节：
- 理论值 z_95×sigma 只保证单日 95%，但连锁效应导致实际更低
- 需要自动搜索：逐步增大 z 值 (1.645→1.96→2.326→2.576→3.0→3.5)
- 直到日交付率≥95% 且周交付率≥85% 同时满足
```
