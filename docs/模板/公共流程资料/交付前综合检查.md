## 八、检查清单：提交前最后一道关

> 本清单源自 `题目与思路/复用提示词-数学建模论文优化.md` 第九节，并扩充为完整版。**提交前逐项打勾，缺一项都可能掉奖。**


### 8.9 文件提交检查

- [ ] 论文 PDF + LaTeX 源码均提交
- [ ] 附录代码单独提供 `.py`/`.m` 文件
- [ ] 删除 `.aux .log .synctex.gz` 等中间文件
- [ ] 图片以 `figures/` 文件夹形式提交
- [ ] 文件名符合赛题要求（如"参赛队号_论文.pdf"）
- [ ] AI 使用声明附件已准备（如使用 AI）

### 8.10 终极自问（评委视角）

提交前问自己 5 个问题：

1. **评委只看摘要，能不能在 60 秒内知道我做了什么、做出了什么？**
2. **每个数字都有代码背书吗？**（如果靠估算，立刻补跑）
3. **方法选择写了"为什么"而不是"是什么"吗？**
4. **结果解读说了"好不好"和"为什么"吗？**（不能只放数字）
5. **如果我是评委，会给自己几等奖？**（诚实回答，不够好就继续改）
