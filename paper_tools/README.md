2026-09-11，依据用户“不要检测任何的哈希”要求，将技能提供的 tools/latex/scripts/latex_paper.py 适配为 latex_paper_nohash.py。原始技能文件保持只读，未运行其初始化、绑定、构建或验收中的哈希逻辑。

保留原工具的模板初始化、资源范围约束、无 shell escape 隔离编译、原子发布、引用/公式/图表/篇幅、编译警告、PDF 页型/空白页/字体嵌入/DPI 检查。将摘要函数全部移除，改为大小和纳秒修改时间及相对路径的字典。复制 PDF 时保留修改时间，使构建记录能对应发布文件。

工具路径可用 MATH_MODELING_SKILL_ROOT 指定；默认使用本机已读取的技能位置。运行时 PATH 应包含 C:/texlive/2025/bin/windows；LC_ALL=C 和 LANG=C 用于避免 TeX Perl 环境区域提示。

export_smoke 仅为从内置模板初始化的最小真实样例，用于早期验证实际编译、图资源、PDF 渲染和压缩链路，不是论文，不等于 W1/W2 或完整质量通过。
